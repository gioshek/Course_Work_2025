# Course Work 2025

## Шумовые и Процедурные текстуры

Данный репозиторий содержит курсовую работу, посвящённую сравнению
процедурных шумов, применяемых в компьютерной графике и генерации текстур.

⚠️ **Важно:**  
Полная реализация проекта находится в отдельной ветке  
➡️ **`full-project`**

Основная ветка (`main`) содержит только описание проекта.

---

## 📌 Цель работы

Целью курсовой работы является:

- реализация нескольких процедурных шумов;
- сравнение их характеристик;
- анализ влияния fBm (Fractal Brownian Motion);
- исследование спектральных свойств шумов с помощью FFT.

---

## 🧠 Реализованные методы

В работе реализованы следующие виды шумов:

- **Perlin Noise**
- **Value Noise**
- **Simplex Noise**
- **fBm (Fractal Brownian Motion)** на основе каждого базового шума

Каждый метод анализируется для трёх частотных режимов:

- **LOW**
- **MID**
- **HIGH**

---

## 📊 Метрики сравнения

Для каждого шума вычисляются следующие характеристики:

- **Энтропия**

  `H = -∑ p(x) log₂ p(x)`

- **Пространственная автокорреляция**
- **Время генерации**
- **Спектральный анализ (FFT)**

Результаты сохраняются в файл `metrics.csv`.

## 🧾 Основные выводы

1. **Value Noise** является самым быстрым методом генерации.
2. **Simplex Noise** обеспечивает высокую пространственную корреляцию,
   но имеет высокую вычислительную стоимость.
3. Использование **fBm** повышает детализированность шума,
   но значительно увеличивает время генерации.
4. FFT-анализ подтверждает различие спектральных характеристик шумов.
5. Выбор метода зависит от требований к скорости и визуальному качеству.
